Set up the shared reflection workspace

The website runs from your Sec 3 EYE Review GitHub repository. Supabase handles teacher login and private paper storage. A Cloudflare Worker and D1 hold shared content and anonymous class summaries.

No payment card is required for this method. Keep Supabase, Cloudflare Workers and D1 on their Free plans. Do not activate Cloudflare R2. The application blocks new uploads at 750 MB, below Supabase Free's 1 GB file-storage allowance.

Uploading the website and connecting the backend are separate. Until the backend is connected, the teacher page opens in a labelled local preview whose changes stay on that browser.

Before you begin: identify the repository name

Open your Sec 3 EYE Review repository on GitHub. Its address has the form:

https://github.com/dmn-math/REPOSITORY-NAME

Write down the final part shown as REPOSITORY-NAME. You will insert that exact spelling in the URLs below.

1. Upload the website to Sec 3 EYE Review

  1. Extract the downloaded ZIP.
  2. Open UPLOAD_TO_GITHUB.
  3. Copy the entire math-workspace folder into the root of your Sec 3 EYE Review repository. Do not place it in DMN-Math-Resources.
  4. Use GitHub Desktop to commit and push the folder. Upload the extracted folder, not the ZIP.
  5. In that repository, open Settings → Pages and ensure GitHub Pages deploys from the branch/folder used by your existing site.
PageAddress
Teachershttps://dmn-math.github.io/REPOSITORY-NAME/math-workspace/
Studentshttps://dmn-math.github.io/REPOSITORY-NAME/math-workspace/reflection.html

2. Configure Supabase login

  1. Open the Supabase project you already created.
  2. Open Authentication → Providers → Email. Ensure Enable Email provider is on. Keep Confirm email on, then save.
  3. Open Authentication → URL Configuration.
  4. Set Site URL to:
    https://dmn-math.github.io/REPOSITORY-NAME/math-workspace/index.html
  5. Add both redirect URLs:
    https://dmn-math.github.io/REPOSITORY-NAME/math-workspace/index.html
https://dmn-math.github.io/REPOSITORY-NAME/math-workspace/index.html?recovery=1
  6. Open Authentication → Users → Add user. Create your owner account with a strong password and mark the email as confirmed. Use this same email later for OWNER_EMAIL.
  7. Open Project Settings → API. Copy the Project URL and publishable key (the legacy anon key also works).

For additional teachers, you can create and confirm their accounts yourself. Supabase's default email sender has restrictions; configure custom SMTP only if teachers must receive their own confirmation and password-reset emails.

3. Create private file storage in Supabase

  1. In Supabase, open Storage.
  2. Select New bucket.
  3. Name it exactly dmn-math-files.
  4. Keep Public bucket off. Set the file-size limit to 20 MB, if that option is shown.
  5. Create the bucket. You do not need to create a public access policy; files are accessed securely through the Worker.
  6. Open Project Settings → API Keys. Copy the protected service_role key. This key is used only once in a terminal command below. Never put it in GitHub, wrangler.jsonc, workspace-config.js, a screenshot or a message.

4. Install the backend tools on Windows

  1. Install the current Node.js LTS version from nodejs.org.
  2. Open the extracted package's SOURCE folder in File Explorer.
  3. Click the address bar, type powershell and press Enter.
  4. Use the commands ending in .cmd; this avoids the PowerShell script-execution error you encountered.
npm.cmd install
npx.cmd wrangler login

Your browser will open Cloudflare's consent page. Approve the Wrangler login. This does not activate R2 or add a payment method.

5. Create only the free Cloudflare D1 database

Run:

npx.cmd wrangler d1 create dmn-math-db

Copy the database ID printed by the command. Do not run any R2 bucket command.

6. Configure the Worker

Open SOURCE/backend/wrangler.jsonc in Notepad or Visual Studio Code and replace:

FieldWhat to enter
OWNER_EMAILYour confirmed owner login email
SUPABASE_URLYour Supabase Project URL
SUPABASE_PUBLISHABLE_KEYYour public publishable/anon key
database_idThe database ID from Step 5
SUPABASE_STORAGE_BUCKETLeave as dmn-math-files
ALLOWED_ORIGINSLeave as https://dmn-math.github.io; a repository path is not included here

Save the file. Then place the service-role key in Cloudflare's protected secret store:

npx.cmd wrangler secret put SUPABASE_SERVICE_ROLE_KEY --config backend/wrangler.jsonc

When PowerShell asks for the secret value, paste the Supabase service_role key and press Enter. It will not be written into your project files.

7. Create the tables and deploy

npm.cmd run backend:migrate
npm.cmd run backend:deploy

Copy the Worker address printed after deployment, for example:

https://dmn-math-api.YOUR-SUBDOMAIN.workers.dev

Open https://YOUR-WORKER-ADDRESS/api/health. A correct setup reports ready: true, storage: "supabase" and uploadLimitMb: 750.

8. Connect the uploaded website

  1. In your local package, open UPLOAD_TO_GITHUB/math-workspace/workspace-config.js.
  2. Enter the Worker address, Supabase Project URL and public publishable key:
window.DMN_WORKSPACE_CONFIG = {
  apiUrl: "https://dmn-math-api.YOUR-SUBDOMAIN.workers.dev",
  supabaseUrl: "https://YOUR-PROJECT.supabase.co",
  supabasePublishableKey: "YOUR_PUBLIC_PUBLISHABLE_KEY"
};

Only the public publishable key belongs here. Never add the service-role key. Upload this revised workspace-config.js to the same math-workspace folder in your Sec 3 EYE Review repository, then commit and push.

9. Verify the workflow

  1. Open the teacher URL and sign in using your confirmed owner account.
  2. Create a small test paper, upload a PDF, crop one complete question and save its tags.
  3. Publish the reflection and open the generated student link in a private browser window.
  4. Create a test class, use its shared class link, submit one anonymous reflection and confirm the class summary appears. Students should not enter names or individual student codes.
  5. In Supabase Storage, open dmn-math-files and confirm the test PDF/crop is present.

Security and limits

  • The bucket is private. Draft files require an approved teacher login; students receive only files referenced by a published reflection.
  • The application accepts PDF, PNG, JPEG and WebP files up to 20 MB each.
  • New uploads stop at 750 MB, leaving space below Supabase Free's 1 GB allowance.
  • The service-role key exists only in Cloudflare's protected Worker secrets. If it is ever exposed, revoke it in Supabase and enter the replacement using wrangler secret put.
  • Supabase Free projects may pause after inactivity. Opening the site again may require the project to resume.
This package does not activate paid services and does not require Cloudflare R2. Your Sec 3 EYE Review repository is changed only when you commit and push the extracted website folder.
